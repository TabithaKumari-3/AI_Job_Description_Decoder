# 💼 AI Job Description Decoder

AI Job Description Decoder is a Streamlit web application that helps users quickly understand and analyze a job description.

## 📌 Project Overview

Job descriptions can contain a lot of information about skills, experience, education, requirements, and responsibilities.

This application takes a job description as input and extracts important information into simple sections.

## ✨ Features

- 🛠️ Detects technical skills
- 💼 Extracts experience requirements
- 🎓 Detects education and qualifications
- 📋 Displays important requirements
- 🔑 Extracts important job-related keywords
- 🖥️ Simple and user-friendly Streamlit interface

## 🛠️ Technologies Used

- Python
- Streamlit
- Regular Expressions
- Git
- GitHub
